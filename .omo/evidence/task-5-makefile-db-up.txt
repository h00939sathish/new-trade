in docker-compose.yml. Compose errored:
  "service 'kafka' not found"

  docker compose up -d postgres redis

VERIFICATION:
  Docker daemon not available on this Windows host, so verified by:
  1) `grep` against docker-compose.yml: only `postgres` and `redis`

     `prometheus`/`grafana`/`trading-app` are not brought up by
     db-up (trading-app is invoked via `run`; observability stack
     is started separately).
  2) Updated Makefile is consistent with docker-compose.yml service
     names.

on the host, that's a separate environment issue.
