# Project Initialization

## Overview
Multi-agent AI trading system. Built from scratch with institutional-grade architecture. All research and architecture decisions documented in `plan.md`.

## Tech Stack
- **Core Engine**: Rust (NautilusTrader patterns)
- **ML/Strategies**: Python 3.12+ (Ray, LightGBM, PyTorch)
- **Message Routing**: Go
- **Event Bus**: Apache Kafka + Schema Registry (Avro)
- **Stream Processing**: Apache Flink
- **Feature Store**: Feast
- **RL Framework**: Ray RLlib
- **Time-Series DB**: TimescaleDB
- **Cache/State**: Redis
- **Orchestration**: Kubernetes + Istio
- **Observability**: Prometheus + Grafana + OpenTelemetry

## Project Structure
```
new-trade/
├── plan.md            # Master plan, architecture, research, roadmap
├── init.md            # This file — project overview and conventions
├── CHANGELOG.md       # Track all changes to the system
├── graphify-out/      # Knowledge graph outputs (generated by graphify)
├── docs/              # Architecture docs, ADRs, diagrams
├── src/
│   ├── engine/        # Rust core engine
│   ├── agents/        # Python agent implementations
│   ├── routing/       # Go message routing middleware
│   └── api/           # REST/gRPC API surface
├── deploy/            # K8s manifests, Helm charts, Terraform
├── tests/             # Integration and system tests
└── scripts/           # Dev scripts, CI/CD helpers
```

## Conventions
- All agent communication via Kafka (Avro schemas)
- Event sourcing for every state change
- Deterministic replay from event store
- Strategies run in sandboxed isolation
- Every component has metrics, traces, and logs
- Pre-trade risk validation for every order
- Changes tracked in CHANGELOG.md

## Getting Started
1. Read `plan.md` for full architecture
2. Check `CHANGELOG.md` for latest changes
3. Run `graphify .` after changes to update knowledge graph
4. See `docs/` for ADRs and detailed specs

## Graphify
This project uses [graphify](https://github.com/safishamsi/graphify) to maintain a queryable knowledge graph of the entire codebase. After making changes, run:
```
/graphify .
```
This generates `graphify-out/` with HTML visualization, report, and JSON graph.
